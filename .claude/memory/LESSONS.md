# LESSONS.md — Registro de Aprendizados do Agente

Este arquivo é mantido pelo agente Claude Code. Sempre que um padrão relevante,
uma armadilha evitada ou um aprendizado operacional for identificado, registre aqui
no formato abaixo. Não edite manualmente exceto para corrigir entradas incorretas.

## Formato de Registro

```
[AAAA-MM-DD] LIÇÃO: <descrição concisa do aprendizado>
CONTEXTO: <situação que gerou o aprendizado>
APLICAÇÃO: <quando/como aplicar este aprendizado no futuro>
```
